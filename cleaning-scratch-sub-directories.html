Cleaning Scratch Sub-directories

  • Jan 09, 2023
  • Categories: Snippet
  • Tags: #storage #snippets

We recently ran into an issue with a high speed scratch file system after some drive failures. While the metadata was intact we could not guarantee that any of the user data was any good. Since the metadata was good, we could keep the top level user scratch directories intact and remove all other files under them, saving a bit of time recreating everything.

find . -maxdepth 2 -mindepth 2 -exec rm -rf {} \;

This snippet should be run with care.
